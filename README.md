# ai-tools

`@minhluudev/ai-tools` is a personal CLI for installing AI tools and agent skills that I use in my own workflow.

## Install

```bash
npm install -g @minhluudev/ai-tools
```

## Usage

```bash
ai-tools
```

Main menu:

1. `Install agent skills`
2. `Manage skills`
3. `Cancel`

Controls:

- `← →` switch tabs
- `↑ ↓` move
- `space` or `enter` select
- `q` or `esc` cancel

`Install agent skills`
- installs selected skills into `~/.codex`, `~/.claude`, `./.codex`, or `./.claude`
