# Frameworks

**React:** Pure render; effects sync externals; clean up and guard stale results.

**Next.js:** Check router/version, server/client boundary, trusted identity, cache scope/invalidation.

**Laravel:** Use policies, tenant-scoped queries, allowed writes, atomic transactions, idempotent jobs.

**NestJS:** Runtime-validate DTOs; guards/services enforce object access; no request state in singletons.
